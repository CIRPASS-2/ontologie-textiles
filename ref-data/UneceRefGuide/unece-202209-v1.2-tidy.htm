1 Introduction

Codes and identifiers are essential components of any machine-to-machine information flow. They have been developed over time to facilitate the flow of standardized data that can be easily validated for correctness to ensure consistent semantics (e.g., plain text versus coded text).

1.1 Objective

The objective of this document is to identify and describe code lists and identifiers supporting the business processes and transactions for traceability and transparency in the textile and leather value chains. In addition, the annex contains references to valuable glossaries and documents.

1.2 Reference documents

Knowledge and application of the following documents is crucial for the use of codes lists and identifiers specified in this document.

· UNECE Recommendation n°46 on "Enhancing traceability and transparency for sustainable value chain in the garment and footwear sector" (2022)

· UN/CEFACT, Business Requirement Specification for Traceability and Transparency in the Textile and Leather Sector, Part 1: High-Level Process and Data Model (2021).

· UN/CEFACT, Business Requirement Specification for Traceability and Transparency in the Textile and Leather Sector, Part 2: Use Cases and CCBDA Data Structures (2021)

· UNECE, Business Process Analysis for Sustainability and Circularity in Textile Value Chains (2021).

· UNECE, Business Process Analysis for Sustainability and Circularity in Leather Value Chains (2021).

· UNECE, Accelerating action for a sustainable and circular garment and footwear industry: which role for transparency and traceability of value chains? Policy paper (2020).

· UNECE, TEXTILE4SDG12: Transparency in Textile Value Chains in Relation to the Environmental, Social and Human Health Impacts of Parts, Components and Production Processes (ECE/TRADE/439) (2017).

· UNECE, Traceability for Sustainable Trade: A Framework to Design Traceability Systems for Cross Border Trade (ECE/Trade/429) (2016).

· UN/CEFACT Code Management User Guide, 8 March 2018.

1.3 Audience

The audience of this document is all users who are interested in the textile and leather data model, and particularly in the application of code lists and identifiers, supporting information exchange in textile and leather value chains.

1.4 Status of this document

This document will be used as a reference during the implementation phase of information exchanges as described within the supporting UN/CEFACT Business Requirements Specification (BRS) documents for traceability and transparency in the textile and leather sector. The number and content of code lists and identifiers might change over time[1]. For some information entities different code lists might be available (e.g., for classification). The appropriate code list often depends on the context or requirements of the user community.

1.5 Document context

This document is created to support the UNECE-UN/CEFACT "Transparency and Traceability for Sustainable Textile and Leather Value Chains" project. Especially regarding the Business Information Entities (BIE) used to exchange traceability and transparency information as specified within the Business Requirements Specification (BRS) documents.


2 Overview of code lists

In this document, a number of code lists and identifiers has been identified which may be used when exchanging information between business partners. The use of code lists and identifiers depends on the context and requirements of the stakeholders regarding the implementation of information exchange standards. Some referenced code lists and identifier schemes listed in this document are not free of charge, such as those of ISO and GS1.

3 Overview of identifiers

Unique identifiers are important for the traceability of assets (material/products) including the logistics unit(s) which contain them. Traceable assets and their logistics units make use of unique identifiers. The ISO/IEC 15459 (part 3) specifies a unique, non-significant, identifier (UID) for products and/or items, represented in a barcode label or other media attached to or incorporated into an item. The UID will start with a string of characters representing the issuing agency code, assigned to the issuing agency by a registration authority. There are different agencies which issue UIDs. One of them is GS1.

4 Details of code lists

A code list is a type of controlled vocabulary containing a finite list of codes and values that represent the only allowed values for a particular information entity. The format in which code list are published differs a lot. At the moment it is not clear if other formats than publicly published are available.

5 Overview identifier schemes

An identifier is a character string used to identify and distinguish uniquely, one instance of an object in an identification scheme from all other objects within the same scheme, such as a product identification identifier.

In addition, an identifier value may be accompanied by supplementary data components specifying additional information on the identifier, such as the ID, agency ID, version ID etc. In case an identifier of a particular entity is unbounded, each ID will have another agency assigned.
