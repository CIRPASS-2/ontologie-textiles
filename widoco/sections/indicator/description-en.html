EU DPP Textile Indicator Ontology: Description back to ToC

An indicator is not used as a generic container for every numerical or assessment result. Raw results remain assessment results, while thresholds remain assessment criteria and numerical magnitudes use the shared quantitative-value model.

dpp:QualityIndicator represents a product quality characteristic in CORE. txtind:DurabilityIndicator represents derived information used to interpret or communicate durability-related evidence. An indicator concerning a characteristic is not necessarily an instance of that characteristic. Durability constructs, derived indicators, assessment results and quantitative values remain distinct. The existing subclass of txtind:Indicator and non-logical dcterms:relation to CORE are retained; no subclass relationship to dpp:QualityIndicator is asserted.
